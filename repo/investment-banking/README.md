# Investment Banking / 投资银行

**核对时间：** 2026-11-18T23:44:34+08:00（Asia/Shanghai） · **本专题：** 48 个公开仓库。

把财报数据与模型工程分开，覆盖公司估值、并购/LBO、股权与债务资本市场，以及明确标注的周边工程。资本市场系统不会被描述成投行内部并购工具。

[Repo 总目录](../README.md) · [公开来源账本](../finance-topics.json) · [Repo Discussions](https://github.com/pengpengyi92/p-finance/discussions/categories/repo)

这是当前已核验候选的收录，不是全球全集或生产背书。同一仓库也可能出现在 Corporate Banking, FICC, Asset Custody；每页写的是该用途。

## 起步路线

- 从 [SEC EDGAR Developer Resources](https://www.sec.gov/about/developer-resources) 和 Edgartools/Arelle 对照申报版本、财年、单位、XBRL 标签与币种。
- 用同一组虚拟财报手算 FCFF、WACC 和桥接净债务，再比较 DCF 与可比；在并购例子里分别记录对价、融资、股数变化及协同假设。
- DCM 用同一票息和结算规则比对 FinancePy/QuantLib/Strata；融资稀释单看 OCF。[既有 IB 机构导读](../banking-capital/investment-banking.md) · [PE](../banking-capital/private-equity.md) · [VC](../banking-capital/venture-capital.md)。
