## 起步路线

- 从 [原有 FICC 深度导读](README.md) 开始：固定 day count、结算时区、期限、插值和报价基准；对照 PV、DV01 与债券期货 implied repo。
- 商品线先用 Equinor Curvy/商品合成案例验证交割窗口、峰谷定义、加权平均和 DST；能源或商品数据 API 的订阅与再分发不随代码许可获得。
- [机构与腾讯历史附录](../ficc-institutions.md)区分上游归属与用途。商户汇率与结算回执不可当作可交易报价或市场定盘。
