# Corporate Banking / 对公银行

**核对时间：** 2026-11-18T23:44:34+08:00（Asia/Shanghai） · **本专题：** 53 个公开仓库。

沿企业客户的资金需求组织：授信与生命周期、贸易融资、现金管理、支付与清算。企业现金管理的主账、银行核心、通道 SDK 和报文规范不是一件事。

[Repo 总目录](../README.md) · [公开来源账本](../finance-topics.json) · [Repo Discussions](https://github.com/pengpengyi92/p-finance/discussions/categories/repo)

这是当前已核验候选的收录，不是全球全集或生产背书。同一仓库也可能出现在 Investment Banking, FICC, Asset Custody；每页写的是该用途。

## 起步路线

- 先用 Fineract 的贷款生命周期与 FinanceToolkit 的借款人财务比率做读码；模型阈值不是任何银行的审批规则。
- 用合成 pain.001、camt.053 或 ACH CTX 对比金额、币种、批次与附言；故意重复导入、缺失附言和逆向冲正，观察能否发现未匹配项目。
- 取 [Swift 官方企业报文说明](https://www.swift.com/standards/iso-20022/iso-20022-faqs/corporates) 对照，再读[旧的银行归属/机构快照](../banking-capital/corporate-banking.md)。真实支付、授信和网络接入均不执行。
